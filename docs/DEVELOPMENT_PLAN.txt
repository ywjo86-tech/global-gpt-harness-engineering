### CMP-107 — Existing Inspection Adapter

**Current source binding:** `runtime/orchestrator/read_only_inspector.py::inspect_read_only`.

The adapter must:
- invoke or semantically wrap the stable-source read-only inspector;
- preserve `write_operations_performed=False`;
- retain fail-closed validation behavior;
- normalize only Repository Intelligence comparison fields into `ProviderResult`;
- never translate static business/gate evidence into runtime authorization;
- never call or modify `runtime/orchestrator/provider_router.py`.

This binding resolves the prior unknown Existing Repository Inspection path.

### CMP-113 — Predecessor Baseline Evidence Verifier

**Inputs:** PHASE 1 stable baseline ref/SHA, predecessor evidence references, stage-gate/regression completion evidence supplied by PHASE 1.  
**Output:** `PredecessorBaselineEvidenceRecord` with `verified=true|false`, immutable ref and evidence references.  
**Prohibition:** it cannot create, repair, complete, qualify or reconfirm the Full Plan baseline on behalf of PHASE 1. Missing evidence returns false and keeps entry closed.

### CMP-102 — PoC Entry Gate

Inputs: predecessor evidence record, current-source revalidation, version qualification, Dangerous Work install approval, controlled-baseline guard state.  
Any missing/ambiguous condition returns `ENTRY_CLOSED`. Existing Full Plan stage gates remain external authority; CMP-102 does not reproduce them.

### CMP-115 — Backend Independence Verifier

Runs the provider contract against a test matrix where execution-backend identifiers are absent, Codex-labeled and Full-MCP-labeled. Repository Intelligence outputs/contracts must remain semantically identical except non-material environment metadata. Direct import/reference to backend-specific runtime interfaces from `poc/graphify` is prohibited.

### CMP-116 — Controlled Baseline Guard

Baseline hash/ref and protected Full Plan Core paths are treated as immutable PHASE 2 inputs. If a required Graphify change would modify Full Plan Core, the guard produces `CONTROLLED_CHANGE_REQUIRED` and closes the PoC path until the external sequence completes:

```text
Change Request
→ Impact Analysis
→ Controlled Change
→ Regression Test
→ Baseline Reconfirmation
```

### CMP-114 — PHASE 3 Handoff Packager

Packages only:
- Graphify decision and conditions
- recommended Repository Intelligence provider mode
- Existing Inspection fallback contract
- canonical verification rules
- backend-independence evidence
- generated-artifact policy status/prerequisite
- unresolved limitations
- evidence index
- explicit `NEXT_MASTER_PHASE=PHASE_3_EXECUTION_BACKEND_CONTRACT_FINALIZATION`

It must not design or implement the Execution Backend Contract, Full MCP, AI Office or Jarvis.


### CMP-117 — Current Repository Intelligence Boundary Guard

Valid provider capabilities are limited to repository structure, symbol/dependency/reference/path/neighbor/change-impact, freshness/confidence and related investigation support. Memory persistence, project continuity and workflow/context assembly APIs are invalid capabilities.

### CMP-118 — Memory Independence Verifier

Performs static and configuration-level verification only. It must detect and fail on:
- imports/packages/runtime handles for Memory Adapter
- Obsidian vault/path/API dependency
- Notion API/database dependency
- Graphify configuration requiring any memory system
- Graphify output routing directly to Obsidian/Notion

It must not connect to those systems as part of PHASE 2.

### CMP-119 — Source Precedence Verifier

Uses canonical repository/baseline evidence plus synthetic lower-priority conflicting statements to prove that repository/baseline evidence controls the verdict. This is a verification fixture, not a Memory Adapter implementation.

### CMP-120 — Context Assembly Boundary Guard

Rejects code/config/contracts that implement Memory Capture, Retrieval, Merge, Injection, Context Compression, Notion Projection or Project Context Assembly inside `poc/graphify`.

### CMP-121 — Master Phase Boundary Firewall

Validates that PHASE 2 contains only Graphify PoC responsibilities. It rejects Full Plan implementation/stabilization ownership and any implementation of Execution Backend Contract, Full MCP, AI Office, Jarvis or PHASE 6 Project Continuity Memory.


### CMP-122 — Decision Closure Finalizer

Consumes an immutable `DecisionRecord` whose outcome is exactly one of `GO | CONDITIONAL_GO | NO_GO`. It verifies required decision evidence and independent-review references, then emits `GraphifyDecisionClosureRecord` with `state=GRAPHIFY_DECISION_CLOSED`. It cannot rewrite the provider decision.

### CMP-123 — Reserved Phase Isolation Verifier

Inspects PHASE 2 contracts/configuration/change targets for prohibited PHASE 7 and PHASE 8 capability signatures. Any detected provider-router expansion, provider benchmarking/scoring/automatic fallback/budget policy, or instruction telemetry/optimization/governance runtime capability fails isolation.

# ID-09 Data / Control / State Flow

## Data Flow

1. PHASE 1 `FULL_PLAN_STABLE_BASELINE` evidence is read-only verified.
2. Current source/version/install approval/controlled-baseline prerequisites are checked.
3. Entry OPEN 후 disposable source snapshot을 만든다.
4. 동일 scenario를 Graphify와 Existing Inspection에 전달한다.
5. canonical/freshness/error/fallback evidence를 생성한다.
6. Backend Independence, Current Repository Intelligence boundary, Memory Independence, Source Precedence and Context Assembly separation을 검증한다.
7. PHASE 7 / PHASE 8 reserved-capability isolation을 검증한다.
8. regression/independent review 후 Decision Evaluator가 `GO | CONDITIONAL_GO | NO_GO` 중 하나를 확정한다.
9. Decision Closure Finalizer가 decision을 변경하지 않고 `GRAPHIFY_DECISION_CLOSED`를 기록한다.
10. PHASE 3 Handoff Package를 생성한다.

## Control Flow

```text
FULL_PLAN_STABLE_BASELINE VERIFIED
        ↓
ENTRY / SOURCE / VERSION / PERMISSION GUARDS
        ↓
ISOLATED CURRENT-REPOSITORY INTELLIGENCE POC
        ↓
CANONICAL / FRESHNESS / FALLBACK
        ↓
BACKEND / MEMORY / SOURCE-OF-TRUTH / CONTEXT BOUNDARIES
        ↓
PHASE 7 / PHASE 8 ISOLATION
        ↓
REGRESSION + INDEPENDENT REVIEW
        ↓
GO | CONDITIONAL_GO | NO_GO
        ↓
Decision Record Finalized
        ↓
GRAPHIFY_DECISION_CLOSED
        ↓
PHASE 3 HANDOFF
```

## State Transitions

| Current State | Event | Next State | Failure / Route |
|---|---|---|---|
| `ENTRY_CLOSED` | predecessor evidence verified | `PREDECESSOR_VERIFIED` | remain CLOSED |
| `PREDECESSOR_VERIFIED` | source/version/permission pass | `ENTRY_OPEN` | drift/CLOSED |
| `ENTRY_OPEN` | disposable env sealed | `ENV_READY` | `BLOCKED_ENV` |
| `ENV_READY` | providers ready | `PROVIDERS_READY` | fallback path |
| `PROVIDERS_READY` | comparative/canonical/freshness complete | `COMPARISON_COMPLETE` | `POC_INCOMPLETE` |
| `COMPARISON_COMPLETE` | backend/memory/source/context + reserved-phase isolation pass | `BOUNDARIES_VERIFIED` | `BOUNDARY_VIOLATION` |
| `BOUNDARIES_VERIFIED` | regression/review pass | `REVIEW_READY` | regression fail |
| `REVIEW_READY` | sealed provider decision | `DECISION_RECORDED` | decision blocked |
| `DECISION_RECORDED` | closure validation pass | `GRAPHIFY_DECISION_CLOSED` | closure blocked |
| `GRAPHIFY_DECISION_CLOSED` | PHASE 3 package complete | `PHASE3_HANDOFF_READY` | handoff incomplete |
| any state | Full Plan Core change required | `CONTROLLED_CHANGE_REQUIRED` | external route |

`GRAPHIFY_DECISION_CLOSED` is reachable from GO, CONDITIONAL_GO and NO_GO alike.
